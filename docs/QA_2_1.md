## 未完成的外部验收／已知边界

1. 不是 iPhone Safari／Android Chrome 实机测试；微信扫码、PNG/SVG 实机下载及实际二维码解码待确认。测试浏览器拒绝 data: 下载，未绕过该策略。自动测试已验证 PNG/SVG payload，UI 已确认生成和下载入口。
2. 可选 Web Speech 能力已实现；未触发真实麦克风权限，授权、拒绝、识别成功及服务失败未实测。无麦克风授权也可文字使用；浏览器语音服务可能需要网络。
3. 地点、合作、社区内容和医疗状态为概念／样例。没有真实地图导航、直播、AI 后端、支付、库存、物流、预约名额或跨设备账户。
4. 2.0 状态兼容性通过保存状态 fixture 的 JSON 恢复测试；未对真实用户浏览器的历史数据做迁移或清理。
5. 未执行生产部署、main 合并或真实用户交易。新分支是否产生 Vercel Preview 以实际 GitHub 状态为准。

推荐顺序：团队查看截图及功能分支 → 真机扫码和语音测试 → 批准 PR／合并／上线 → 核实真实经营内容与服务接口。
