## 实际限制 / 待确认

- 2D 照片与原创插画场景；不是 rigged 3D 模型或独立角色动画系统。
- 猫、猫咖、种子粉丝及排名是演示；数据仅本浏览器，不跨队友同步。
- 商城图为品类概念图，不是可履约实拍商品；支付、照护、生日和兑换仍为模拟流程。
- reduced-motion 已实现 CSS，但本轮未实际切系统偏好验收；未测真实设备触屏、Safari、真实语音及声音播放效果。
- 未接入真实 AI、直播、导航、后台或服务器；未自动合并 main，不更新 Production。
- Vercel Preview 可用性以推送后的部署记录和最终交付消息为准。
